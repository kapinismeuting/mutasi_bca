                          HOW TO RUN THE APP
================================================================================

QUICK START (3 steps):
  1. pip install -r requirements.txt
  2. chmod +x run_streamlit.sh              (Linux/Mac only)
  3. ./run_streamlit.sh                     (or run_streamlit.bat on Windows)
  
  Then open: http://localhost:8501

DETAILED STEPS:
  1. Ensure Python 3.7+ is installed
  2. Navigate to project directory: cd mutasi_bca
  3. Create virtual environment (optional):
     python3 -m venv venv
     source venv/bin/activate  # or venv\Scripts\activate on Windows
  4. Install dependencies:
     pip install -r requirements.txt
  5. Run Streamlit app:
     streamlit run streamlit_app.py
  6. Browser opens automatically to http://localhost:8501

================================================================================

MODE 1: INDIVIDUAL FILES
  Input:  folder/ (contains multiple PDFs)

    ├─ Februari.pdf

    ├─ Januari.xlsx    (transactions)

    └─ Maret.xlsx      (transactions)
  
  Use Case: Monthly reports, separate files per month

MODE 2: CONSOLIDATED FILE
  Input:  folder/ (contains multiple PDFs)
    ├─ Januari.pdf
    ├─ Februari.pdf
    └─ Maret.pdf
  
  Output: folder/ (creates single Excel with multiple sheets)
    └─ 2026.xlsx
        ├─ JAN (sheet with transactions)
        ├─ FEB (sheet with transactions)
        └─ MAR (sheet with transactions)
  
  Use Case: Consolidated reports, single file analysis

================================================================================
                          DATA FORMAT SPECIFICATION
================================================================================

EXCEL OUTPUT COLUMNS:
  Column 1: Tanggal (Day: 1-31)
  Column 2: Bulan (Month: 1-12)
  Column 3: Keterangan (Description text)
  Column 4: DB (Debit amount: 1,234.56 format)
  Column 5: CR (Credit amount: 1,234.56 format)
  Column 6: Saldo (Balance: 1,234.56 format)

PDF FORMAT EXPECTED:
  Transaction Row: "DD/MM [Description] [Amount] [DB/CR] [Balance]"
  Summary Rows: "SALDO AWAL:", "MUTASI CR:", "MUTASI DB:", "SALDO AKHIR:"
  Number Format: 1,234.56 (comma separator, dot decimal)

================================================================================
                         TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: "Port 8501 already in use"
  Solution: streamlit run streamlit_app.py --server.port 8502

Problem: "Folder not found" error
  Solution: Use absolute paths (e.g., /home/user/folder, not ~/folder)

Problem: "PDF fails to process"
  Solution: Check file isn't corrupted, verify size < 100MB

Problem: "No results after processing"
  Solution: Verify input folder contains PDF files

Problem: "Permission denied on output folder"
  Solution: Check write permissions (chmod 755 folder_path)

Problem: "Browser won't open"
  Solution: Manually visit http://localhost:8501

Problem: "Python not found"
  Solution: Install Python 3.7+, ensure it's in PATH
